# FEI Test Reports

This directory contains JSON reports generated from running tests on various components of the FEI project.

## Provider Test Reports

- `final_provider_test_report_complete.json`: Complete test report for all providers
- `final_provider_test_report.json`: Test report for providers without tool usage
- `final_provider_test_report_with_tools.json`: Test report for providers with tool usage
- `provider_test_report.json`: Basic provider test report
- `provider_test_report_updated.json`: Updated provider test report

## General Test Reports

- `final_test_report.json`: Final test report for all components
- `final_test_report_with_tools.json`: Final test report for all components with tool usage

## Using the Reports

These reports can be used to:

1. Track the performance of different LLM providers
2. Compare the effectiveness of tool usage across providers
3. Identify areas for improvement in the FEI system
4. Generate visualizations of test results

## Generating Reports

To generate new reports, run the appropriate test scripts in the `tests` directory.
